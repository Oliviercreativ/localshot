Serveur de partage

Le serveur reçoit uniquement les captures que vous partagez. Par défaut, c'est le petit serveur de ce Mac. Vous pouvez indiquer votre Raspberry Pi (adresse Tailscale, par exemple https://pi.tailnet-1234.ts.net).

Chrome vous demandera l'autorisation d'accéder à cette seule adresse. La clé reste dans Chrome, sur ce Mac. Les captures non partagées ne quittent jamais votre ordinateur.
